## 七、明确不做的与原因

- **模块化重构（§架构）**：单模块规模下收益低、风险高（要动全部 Room 迁移与门禁），不做。
- **图表库替换**：自绘 Canvas 已满足需求，换库收益不抵重做成本，不做。
- **规则化数据源 / 社区 Discussions**：都依赖 §三 的规则基建与运营，单独立项。
- **ACRA 崩溃收集**：需要自托管后端（文档给了 Cloudflare Worker 方案）。在你有后端之前，
  建议先做"纯本地崩溃日志导出"（复用现有 LogT 落盘 + 导出分享），**需你拍板**。
