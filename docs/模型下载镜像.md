## 国内可用镜像

按推荐顺序：

1. **gh-proxy.com**（已完整下载并校验，396,705,472 字节，sha256 与官方一致）
   ```text
   https://gh-proxy.com/https://github.com/wuliao00/PriceLens/releases/download/model-qwen3-0.6b-q4km-v1/Qwen3-0.6B-Q4_K_M.gguf
   ```
2. **ghproxy.net**（实测 HTTP 200 / 206，支持 Range，大小与官方一致；未跑完 397MB 全量哈希）
   ```text
   https://ghproxy.net/https://github.com/wuliao00/PriceLens/releases/download/model-qwen3-0.6b-q4km-v1/Qwen3-0.6B-Q4_K_M.gguf
   ```
3. GitHub 官方源（有代理/VPN 时最稳）

镜像都是第三方 GitHub 加速代理，可能失效；只把它们当传输通道。App 下载完成后会用内置的
SHA-256 再校验一次，坏文件/被替换的文件不会安装。

## 下载与校验

PowerShell：

```powershell
$url = 'https://gh-proxy.com/https://github.com/wuliao00/PriceLens/releases/download/model-qwen3-0.6b-q4km-v1/Qwen3-0.6B-Q4_K_M.gguf'
curl.exe -L --retry 3 -o Qwen3-0.6B-Q4_K_M.gguf $url
(Get-FileHash .\Qwen3-0.6B-Q4_K_M.gguf -Algorithm SHA256).Hash.ToLower()
```

最后一行应为：

```text
ac2d97712095a558e31573f62f466a3f9d93990898b0ec79d7c974c1780d524a
```

## 与 App 的关系

- **2.8.0.5 安装包**：应用内下载器仍只写死 GitHub 主源；直连不动时会下载失败。
- **源码当前版本**：`ModelRepository.URLS` 已加入上述两个镜像，`ModelStore` 会按顺序回退，
  并在每个源下载完成后做同样的 sha256 校验；这些改动会随**下一个构建**生效。
- release 包不可 `run-as`，因此不能把模型 `adb push` 进正式包；要么等新版，要么用 debug 包测试。

## 为什么不用 Hugging Face / ModelScope

Qwen 官方的 `Qwen/Qwen3-0.6B-GGUF` 仓库目前只有 `Qwen3-0.6B-Q8_0.gguf`
（639,446,688 字节，sha256 `9465e63a…`），没有本项目使用的 Q4_K_M 这一份；
拿 Q8_0 顶替会改变体积、内存占用与摘要，App 会拒绝安装，所以不作为镜像。
