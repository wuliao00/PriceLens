# PriceLens 比价助手（浏览器扩展）

Chrome / Edge（Manifest V3）扩展：在京东、淘宝、天猫商品详情页右下角注入「PL 比价」浮层。

## 功能

- 读取当前页面商品标题与页面价（只读当前页 DOM，不上传）。
- 展开面板后搜索 B 站评测，展示前 6 条；命中商单/夸大话术的视频挂标签并沉底。
- 「在桌面端打开」通过 `pricelens://product?url=...` 唤起 PriceLens 桌面端（需桌面端 v2.5.0+），
  由桌面端查看历史价、找券、社区与盯价。
- 弹窗可判断当前页是否受支持，并提供桌面端/GitHub 入口。

## 安装（开发者模式）

1. Chrome/Edge 打开 `chrome://extensions`（Edge 为 `edge://extensions`）。
2. 打开「开发者模式」。
3. 点「加载已解压的扩展程序」，选择本目录 `extension/`。
4. 打开一个京东/淘宝/天猫商品详情页，右下角出现「PL 比价」。

正式分发可把本目录压缩为 zip 后按浏览器商店要求提交；解压加载不需要 zip。

## 隐私

- 不读取、不上传页面 Cookie；不注入远程脚本；无埋点。
- 只为 B 站搜索请求 `api.bilibili.com`，并用静态 `rules.json` 设置匿名 Referer/buvid3 请求头。
- 页面标题只在本地作为 B 站搜索关键词；历史价、找券等仍由桌面端在本机请求。
- 扩展不保存浏览记录；B 站结果只在 service worker 内存中缓存 10 分钟。

## 已知限制

- 京东/淘宝/天猫页面结构会改版；标题/价格选择器可能失效，此时面板会显示「页面价未识别」，
  但仍可复制链接或联动桌面端。
- B 站搜索接口可能触发风控/签名失效，面板会显示具体「暂不可用」原因，不会伪造评测。
- `pricelens://` 需要安装/运行 PriceLens 桌面端 v2.5.0+；未安装时浏览器会提示没有可处理的应用。
- 扩展不做价格历史与优惠券抓取，这两块继续由桌面端负责，避免在浏览器里重复维护反爬逻辑。

## 目录

```
extension/
├── manifest.json      # MV3 清单（仅商品页匹配 + 最小权限）
├── background.js      # B站 WBI 搜索、内容风险标记、10 分钟缓存
├── md5.js             # WBI 签名所需 MD5（无外部依赖）
├── risk.js            # 与桌面端同词库的商单/夸大规则（含否定豁免）
├── rules.json         # 给 B站请求补匿名 Referer/buvid3
├── content.js         # Shadow DOM 商品页浮层
├── popup.html/css/js  # 扩展弹窗
└── icons/             # 16/48/128 图标
```
